# Security Policy

## Supported Versions

The following versions of Ayvaaan currently receive security updates.

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅ Yes     |
| < 1.0   | ❌ No      |

---

## Reporting a Vulnerability

The security of Ayvaaan and its users is important to us.

If you discover a security vulnerability, please report it responsibly and privately.

### Contact

Email:

[arlo.myn@proton.me](mailto:arlo.myn@proton.me)

Subject:

 Vulnerability Report - Ayvaaan

---

## What to Include

Please provide:

* Vulnerability description
* Steps to reproduce
* Impact assessment
* Affected version
* Device information
* Screenshots (if applicable)
* Proof of concept (if available)

Example:

```text
Title: Playlist Database Exposure

Version: 1.0.0

Description:
Sensitive playlist information can be accessed through...

Steps:
1. Open...
2. Navigate...
3. Observe...
```

---

## Response Process

After receiving a report:

1. Vulnerability is reviewed.
2. Issue severity is assessed.
3. A fix is developed.
4. Security patch is released.
5. Reporter may be contacted for verification.

Target response time:

* Initial acknowledgement: Within 7 days
* Status update: Within 30 days

---

## Responsible Disclosure

Please:

* Do not publicly disclose vulnerabilities before a fix is available.
* Do not access data belonging to other users.
* Do not perform destructive testing.
* Do not exploit vulnerabilities beyond what is necessary to demonstrate the issue.

We appreciate responsible security research and coordinated disclosure.

---

## Security Practices

Ayvaaan is designed with privacy and security in mind.

Current practices include:

* No embedded API secrets in release builds
* Scoped Storage usage
* Android MediaStore integration
* Local-first music playback
* No hidden telemetry
* No unauthorized data collection
* Secure permission handling
* Dependency version monitoring

---

## Third-Party Dependencies

Ayvaaan may rely on third-party open-source libraries.

Security issues affecting external dependencies should also be reported so they can be evaluated and updated where appropriate.

---

## Privacy

Ayvaaan is an offline-first music player.

The application does not:

* Sell user data
* Track user behavior across apps
* Collect personal information for advertising
* Upload local music libraries to remote servers

Any future cloud-connected features will be documented in the Privacy Policy.

---

## Security Updates

Security-related fixes will be documented in release notes when appropriate.

Critical vulnerabilities may receive expedited patch releases.
